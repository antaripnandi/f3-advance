# F3 Advanced 0.1.0

Initial public build.

- Adds a cleaner F3 debug overlay with color-coded grouped sections.
- Replaces vanilla F3 debug screen.
- Adds per-line JSON config toggles and a fallback in-game config screen.
- Adds Mod Menu and Cloth Config integration when those mods are installed.
- Uses Minecraft registries at runtime for modded biomes, blocks, entities, effects, and dimensions.
- Adds section toggles and an F3+M config shortcut.
- Includes adjustable HUD position, colors, padding, and background transparency.
